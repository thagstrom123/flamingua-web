The German Accusative Case — Den, Einen, Keinen

The accusative case is the first German case you'll learn after the nominative. It's used for the direct object of a sentence — the thing being acted upon. The good news: only masculine articles actually change.

When Do You Use the Accusative?

The accusative marks the direct object — what the verb acts on:

  • Ich trinke den Kaffee. — I drink the coffee.
  • Er kauft einen Apfel. — He buys an apple.
  • Wir haben keinen Hund. — We don't have a dog.

How Articles Change in the Accusative

GenderNominativeAccusativeChange?
Masculineder / ein / keinden / einen / keinenYes
Femininedie / eine / keinedie / eine / keineNo
Neuterdas / ein / keindas / ein / keinNo
Pluraldie / — / keinedie / — / keineNo

Key insight: Only masculine articles change in the accusative. Feminine, neuter, and plural stay exactly the same. This makes it much simpler than it looks.

Example Sentences

  • Ich sehe den Mann. — I see the man. (der → den)
  • Sie möchte einen Tee. — She'd like a tea. (ein → einen)
  • Wir haben keinen Garten. — We don't have a garden. (kein → keinen)
  • Ich kaufe die Milch. — I buy the milk. (feminine — no change)
  • Er isst das Brot. — He eats the bread. (neuter — no change)
  • Hast du einen Bruder? — Do you have a brother? (ein → einen)

Verbs That Take the Accusative

These common A1 verbs always need a direct object in the accusative:

  • haben — to have (Ich habe einen Hund.)
  • kaufen — to buy (Sie kauft den Kuchen.)
  • trinken — to drink (Er trinkt einen Kaffee.)
  • essen — to eat (Wir essen das Brot.)
  • sehen — to see (Ich sehe den Bus.)
  • möchten — would like (Ich möchte einen Apfel.)

Common Mistakes

  • Forgetting to change masculine articles: "Ich trinke der Kaffee" → Incorrect. It should be "Ich trinke den Kaffee."
  • Changing feminine/neuter articles: These don't change. "Ich esse die Suppe" is correct as-is.
  • Confusing kein/keinen: "Ich habe kein Bruder" → Incorrect. Bruder is masculine, so it's "Ich habe keinen Bruder."
